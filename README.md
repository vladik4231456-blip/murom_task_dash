# murom_task_dash

Рабочий сайт доски объявлений с:
- backend на Flask
- SQLite базой данных
- API для авторизации, публикации, комментариев и лайков
- модерацией через защищённую admin-панель
- статическим frontend, который обращается к API

## Локальный запуск

1. Установите зависимости:
   py -m pip install -r requirements.txt

2. Создайте рядом с `app.py` файл `.env` на основе `.env.example` и заполните его своими значениями. Файл `.env` не публикуется и не отправляется в Git.

Пример содержимого `.env`:

```text
ADMIN_EMAIL=ваша-почта@example.com
ADMIN_PASSWORD=длинный-уникальный-пароль
JWT_SECRET=длинная-случайная-строка
FLASK_ENV=development
FLASK_DEBUG=0
SEED_DEMO_DATA=1
PORT=3000
```

3. Запустите сервер:
   py app.py

4. Откройте в браузере:
   http://localhost:3000

Для Linux-хостинга используется команда из `Procfile`:

```text
gunicorn app:app
```

- комментарии

## Структура

- `index.html` — фронтенд
- `style.css` — стили
- `script.js` — логика работы с API
- `app.py` — сервер и API
- `app.sqlite` — локальная база SQLite; на Render используется PostgreSQL через `DATABASE_URL`

## Публикация на бесплатном Render + Neon

Для первого публичного запуска используйте Render для сайта и Neon для постоянной PostgreSQL-базы. Бесплатный Render может засыпать после простоя, но база Neon сохраняется.

1. Создайте аккаунт на `neon.tech`, создайте проект и базу PostgreSQL.
2. Скопируйте в Neon строку подключения `DATABASE_URL`. Не публикуйте её.
3. Создайте репозиторий на GitHub и загрузите туда проект. `.env` и `app.sqlite` благодаря `.gitignore` не попадут в репозиторий.
4. На `render.com` нажмите **New + -> Web Service** и подключите GitHub-репозиторий.
5. В настройках Render укажите:
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `gunicorn app:app`
   - Plan: `Free`
6. В разделе **Environment Variables** добавьте:

```text
ADMIN_EMAIL=ваша реальная почта
ADMIN_PASSWORD=длинный уникальный пароль
JWT_SECRET=длинная случайная строка
DATABASE_URL=строка подключения Neon
FLASK_ENV=production
FLASK_DEBUG=0
SEED_DEMO_DATA=0
```

7. Нажмите **Create Web Service** и дождитесь окончания deploy.
8. Render выдаст адрес вида `https://имя-сервиса.onrender.com`. Это публичный адрес сайта.
9. Откройте его и проверьте регистрацию, вход, публикацию, комментарий, лайк и админ-панель.

Файл `render.yaml` уже содержит команды запуска и безопасные настройки. Секретные значения всё равно нужно заполнить вручную.

После публикации не запускайте `py app.py` для сайта в интернете: это локальный режим. На Render используется Gunicorn.

Перед обновлением делайте копию базы:

```powershell
Copy-Item app.sqlite ("app.sqlite.backup-" + (Get-Date -Format "yyyyMMdd-HHmmss"))
```

## Перед бесплатным хостингом

Для публичного запуска обязательно задайте `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `JWT_SECRET`, `DATABASE_URL` и `FLASK_ENV=production` в настройках хостинга. Не используйте значения из примеров. `CORS_ORIGINS` оставьте пустым, если frontend и backend размещаются на одном домене.

При использовании Neon база не зависит от перезапусков Render. Делайте резервные копии PostgreSQL через инструменты Neon. Бесплатные тарифы могут менять ограничения и засыпать после простоя, поэтому перед запуском проверьте актуальные условия выбранных сервисов.
